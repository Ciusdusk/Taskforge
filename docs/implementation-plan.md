# MVP 迭代计划

任务顺序与范围已确认。T01—T10 每个任务由一个独立会话实现，完成验证后再交接到下一会话。
当前会话仅处理 T01 及其环境恢复；T02 使用 [新会话 prompt](prompts/T02.md)。
每个任务对应可独立审查的 Commit；当前未创建 Commit。

| 任务 | 输入与依赖 | 输出 | 验收条件 |
| --- | --- | --- | --- |
| T01 工程骨架与设计记录 | 已确认的需求和架构 | src 布局、依赖与锁文件、质量配置、设计文档、README | 环境同步、构建、Ruff、mypy 通过；构建包可导入 |
| T02 注册与输入校验 | T01；单个 Pydantic 输入契约 | 注册表、定义、策略、注册错误 | 重名、同步函数、未知任务被拒绝；参数校验及 JSON 往返正确；注册表隔离 |
| T03 持久化提交与查询 | T02；数据模型 | 表、schema、提交与查询 | 非法输入不入库；重开可查；策略快照稳定；失败回滚 |
| T04 原子领取与完成 | T03；一致性规则 | claim_next、finish_attempt | 并发唯一；状态与历史同时提交；拒绝重复完成；故障回滚 |
| T05 单次执行与超时 | T02；执行结果契约 | Executor、超时、执行上下文、日志 | 错误分类准确；协作取消停止；日志可关联 |
| T06 Worker 与并发控制 | T04、T05 | 锁、轮询、槽位、基础执行闭环 | 进程互斥；并发有界且可重叠；业务失败隔离；数据库故障停止领取 |
| T07 持久化重试 | T04、T06 | 策略决策、退避、RETRY_WAIT | 次数有界；配置错误不重试；历史完整；重启不提前执行 |
| T08 停机与崩溃恢复 | T06、T07 | 启动恢复、优雅停机、中断 | 强制退出后可获锁；按预算恢复；恢复再次中断可继续；槽位不提前释放 |
| T09 完整 CLI | T03、T08 | init/submit/worker/list/show/history | CLI 闭环；错误退出码明确；查询无需任务模块；与 Python 行为一致 |
| T10 场景验证与文档 | T01—T09 | 示例、端到端验证、真实记录、完整 README | 步骤可复现；重复副作用与幂等验证；所有检查通过 |
